PHAN I. TONG QUAN KIEN TRUC VA NGUYEN LY HOAT DONG
================================================================================

He thong gom 2 phan chinh chay doc lap:
1. SERVER:
   - Dong vai tro la may chu quan ly kho du lieu thuoc va cong dung tren bo nho RAM.
   - Mo cong TCP 5000, hoat dong theo kien truc Da luong (Multi-threading).
   - Moi Client ket noi toi se duoc tao mot luong (Thread) rieng biet de phuc vu,
     giup phuc vu dong thoi nhieu Client cung luc ma khong bi nghen mang.
   - Du lieu duoc dong bo hoa bang tu khoa "synchronized" de dam bao an toan 
     khi nhieu Client cung doc/ghi dong thoi (Thread-safe).

2. CLIENT:
   - La ung dung giao dien do hoa Desktop bang Java Swing (JFrame).
   - Ap dung mo hinh kien truc MVC (Model - View - Controller):
     + View (BTLLTM.java): Chi chua giao dien (bang bieu, nut bam, hop thong bao),
       tuyet doi khong viet code ket noi Socket truc tiep trong nay.
     + Model (Thuoc.java, CongDung.java): Cac lop dinh nghia thong tin thuc the.
     + Service (ClientService.java): Tang ket noi Socket, gui va nhan du lieu voi Server.
     + Controller (ClientController.java): Cau noi dieu phoi, bat su kien click chuot 
       tu View, goi Service xu ly, roi do nguoc du lieu ve View.
   - Su dung SwingWorker: Moi thao tac mang deu duoc day vao luong chay ngam 
     (Background Thread), giup giao dien khong bao gio bi do, treo (Not Responding).

3. GIAO THUC TRUYEN TIN (PROTOCOL):
   - Client va Server giao tiep bang cac chuoi van ban UTF-8 qua DataInputStream / DataOutputStream.
   - Dinh dang thong diep:
     + Lenh Client gui: "<TEN_LENH>" hoac "<TEN_LENH>|<THAM_SO>"
     + Server tra loi: "OK|<DU_LIEU_HOAC_THONG_BAO>" neu thanh cong.
     + Server tra loi: "ERROR|<NOI_DUNG_LOI>" neu that bai.
   - Du lieu dang bang (danh sach thuoc/cong dung) duoc ma hoa Base64 UTF-8:
     + Cac truong trong 1 dong noi voi nhau bang dau cham (.)
     + Cac dong noi voi nhau bang dau cham phay (;)
     + Giup tranh triet de loi ky tu tieng Viet, dau cach, dau phay hoac ky tu dac biet.

1. FILE Server.java
--------------------------------------------------------------------------------
Doan code 1: Khoi tao ServerSocket va cong ket noi
```java
Store store = new Store();
try (ServerSocket serverSocket = new ServerSocket(PORT)) { ... }
```
- Giai thich:
  + "Store store = new Store();": Khoi tao duy nhat mot doi tuong kho chua du lieu 
    de tat ca cac ClientHandler sau nay dung chung.
  + "new ServerSocket(PORT)": Mo cong mang TCP (port 5000) tren he dieu hanh de 
    lang nghe cac yeu cau ket noi tu Client.
  + Cu phap try-with-resources: Dam bao khi Server tat hoac co loi thi cong 5000 
    se duoc dong lai, tranh bi chiem dung cong (Address already in use).

Doan code 2: Vong lap lang nghe va cap phat da luong
```java
while (true) {
    Socket socket = serverSocket.accept();
    ClientHandler handler = new ClientHandler(socket, store);
    Thread thread = new Thread(handler);
    thread.start();
}
```
- Giai thich:
  + "serverSocket.accept()": Day la ham chan (blocking call). Server se dung doi 
    tai day, khi co Client ket noi toi thi moi chay tiep va tra ve doi tuong Socket.
  + "new ClientHandler(socket, store)": Goi phan viec xu ly cho mot doi tuong moi, 
    truyen Socket cua Client do va kho du lieu dung chung "store".
  + "new Thread(handler); thread.start();": Tao va kich hoat mot luong (Thread) 
    doc lap cho Client do. Luc nay, luong chinh (Main Thread) ngay lap tuc quay lai 
    dau vong lap while de doi Client tiep theo, khong bi nghen.

4. FILE Protocol.java
--------------------------------------------------------------------------------
Doan code 1: Ma hoa va giai ma Base64 tung truong du lieu
```java
public static String encode(String value) {
    if (value == null) value = "";
    return Base64.getEncoder().encodeToString(value.getBytes(StandardCharsets.UTF_8));
}
public static String decode(String value) {
    if (value == null || value.isEmpty()) return "";
    try {
        return new String(Base64.getDecoder().decode(value), StandardCharsets.UTF_8);
    } catch (IllegalArgumentException e) {
        return value;
    }
}
```
- Giai thich:
  + "StandardCharsets.UTF_8": Chuyen doi chuoi tieng Viet co dau thanh mang byte chuan.
  + "Base64.getEncoder().encodeToString(...)": Bien mang byte thanh chuoi ky tu ASCII an toan.
  + Co kiem tra null va bat ngoai le de tranh bi crash khi du lieu rong hoac bi sai format.

Doan code 2: Dong goi va giai ma bang du lieu (encodeRows / decodeRows)
```java
// Dong goi:
for (String[] row : rows) {
    if (result.length() > 0) result.append(";");
    for (int i = 0; i < row.length; i++) {
        if (i > 0) result.append(".");
        result.append(encode(row[i]));
    }
}
// Giai ma:
String[] rows = data.split(";", -1);
for (String row : rows) {
    String[] fields = row.split("\\.", -1);
    ...
    decoded[i] = decode(fields[i]);
}
```
- Giai thich:
  + Moi o du lieu duoc encode Base64. Cac o trong 1 dong ghep boi dau cham (.).
  + Cac dong ghep boi dau cham phay (;).
  + Khi giai ma: Tach theo ";" de duoc cac dong, tach theo "\\." de lay tung o va giai ma Base64.

5. FILE ClientService.java
--------------------------------------------------------------------------------
Doan code 1: Gui yeu cau Socket va bat loi mat ket noi
```java
private String guiYeuCau(String request) throws IOException {
    try (
        Socket socket = new Socket(host, port);
        DataOutputStream out = new DataOutputStream(socket.getOutputStream());
        DataInputStream in = new DataInputStream(socket.getInputStream())
    ) {
        socket.setSoTimeout(5000);
        out.writeUTF(request);
        out.flush();
        return in.readUTF();
    } catch (ConnectException e) {
        throw new IOException("Khong the ket noi toi Server tai " + host + ":" + port + ". Vui long bat Server truoc khi chay Client!");
    }
}
```
- Giai thich:
  + "new Socket(host, port)": Mo ket noi TCP toi Server (127.0.0.1:5000).
  + "socket.setSoTimeout(5000)": Neu sau 5 giay Server khong tra loi thi tu dong huy, tranh bi treo vo han.
  + "catch (ConnectException e)": Bat truong hop nguoi dung quen chua bat Server, 
    nem ra thong bao tieng Viet de hien thi ro rang tren giao dien.

Doan code 2: Kiem tra ket qua tra ve
```java
private String kiemTraPhanHoi(String response) throws IOException {
    String[] parts = response.split("\\|", 2);
    if (parts[0].equals("ERROR")) {

    }

    }

```
- Giai thich:
  + Tach chuoi theo ky tu "|". Neu Server tra ve "ERROR|Ly do", ham se nem ngay IOException 
    chua dung "Ly do" do de Controller bat duoc va hien thi len man hinh.

7. FILE ClientController.java

Doan code 1: Tai du lieu ban dau bang SwingWorker
```java
new SwingWorker<List<List<String[]>>, Void>() {
    @Override
    protected List<List<String[]>> doInBackground() throws Exception {
        List<List<String[]>> ketQua = new ArrayList<>();
        ketQua.add(service.layDanhSachThuoc());
        ketQua.add(service.layDanhSachCongDung());
        return ketQua;
    }
    @Override
    protected void done() {
        try {
            List<List<String[]>> data = get();
            view.hienThiDanhSachThuoc(data.get(0));
            view.hienThiDanhSachCongDung(data.get(1));
            view.hienThiKetQua("Da ket noi Server va tai du lieu thanh cong.");
        } catch (Exception e) {
            Throwable cause = (e.getCause() != null) ? e.getCause() : e;
            view.hienThiKetQua("LOI KET NOI: " + cause.getMessage());
        }
    }
}.execute();
```
- Giai thich:
  + "doInBackground()": Chay tren LUONG NGAM (Background Thread). Goi service de lay du lieu tu mang.
  + "done()": Tu dong chay tren LUONG GIAO DIEN (EDT) khi doInBackground xong. 
    Nhan ket qua bang "get()" va do vao 2 bang JTable.
  + "e.getCause()": Khi SwingWorker bi loi, no se boc ngoai le trong ExecutionException. 
    Dung e.getCause() se lay dung thong diep loi goc de in ra giao dien.

Doan code 2: Xu ly xoa thuoc kem hop thoai xac nhan

--------------------------------------------------------------------------------
Chuc nang 1: Khoi dong va Ket noi mang Server - Client
--------------------------------------------------------------------------------
1. Nguoi dung chay Server.java:
   - Server.main() -> new Store() (nap 13 thuoc va 7 cong dung tren RAM).
   - Mo cong: new ServerSocket(5000).
   - Server dung tai lenh: serverSocket.accept() cho Client toi.
2. Nguoi dung chay BTLLTM.java:
   - BTLLTM.main() -> Khoi tao giao dien (View).
   - Khoi tao ClientService("127.0.0.1", 5000).
   - Khoi tao ClientController(view, service).
   - Controller goi taiDuLieuBanDau().
   - Controller tao SwingWorker mo Socket toi 127.0.0.1:5000.
3. Server chap nhan ket noi:
   - serverSocket.accept() nhan ket noi, in: "Client ket noi: /127.0.0.1".
   - Server tao Thread moi chay ClientHandler.
4. Client gui 2 lenh:
   - Lenh 1: "LIST_THUOC" -> Server tra ve ma tran thuoc ma hoa -> Client giai ma va hien thi Tab 1.
   - Lenh 2: "LIST_CONGDUNG" -> Server tra ve ma tran cong dung -> Client giai ma va hien thi Tab 2.
5. Hop ket qua in: "Da ket noi Server va tai du lieu thanh cong."

================================================================================
PHAN IV. LUONG XU LY DA LUONG (MULTI-THREADING ARCHITECTURE)
================================================================================

1. PHIA SERVER:
   - Main Thread: Chuyen chay vong lap vo han accept() de don Client.
   - ClientHandler Threads: Moi khi co 1 Socket ket noi den, mot Thread moi duoc cap phat 
     (Thread thread = new Thread(handler); thread.start();). Cac luong nay hoat dong doc lap, 
     phuc vu nhieu Client dong thoi.
   - Store Lock: Khi nhieu ClientHandler Thread cung muon sua Store, co che synchronized se 
     tao hang doi (Monitor Lock) cho tung luong thuc hien, dam bao an toan 100%.

2. PHIA CLIENT:
   - Main Thread: Khoi dong chuong trinh.
   - Swing Event Dispatch Thread (EDT): Luong chuyen trach quan ly giao dien, ve cac 
     Component va bat su kien click chuot.
   - SwingWorker Background Thread: Luong ngam thuc hien I/O mang (gui nhan Socket qua mang LAN/Internet). 
     Nho tach rieng luong nay ma khi cho Server phan hoi, nguoi dung van co the keo tha, phong to, 
     thu nho cua so ma khong bao gio bi hien tuong treo ung dung.


================================================================================
PHAN V. CAC CAU HOI VAN DAP THUONG GAP KHI BAO VE BTL & GOI Y TRA LOI
================================================================================

Cau 1: Tai sao Server phai su dung da luong (Multi-threading)?
-> Tra loi: Neu khong dung da luong, khi mot Client ket noi va gui yeu cau thi Server se bi 
blocked (nghen). Tat ca cac Client khac se phai cho den khi Client dau tien ngat ket noi. 
Viec tao moi mot Thread cho moi ket noi (ClientHandler) giup Server phuc vu dong thoi hang tram 
Client cung luc.

Cau 2: Tu khoa "synchronized" trong Store.java co y nghia gi?
-> Tra loi: Vi Server la da luong, neu 2 Client cung bam xoa hoac doc du lieu tai cung mot thoi diem 
thi se xay ra xung dot du lieu (Race Condition / ConcurrentModificationException). Tu khoa "synchronized" 
dam bao tai mot thoi diem chi co duy nhat 1 luong duoc thao tac tren kho du lieu.

Cau 3: Tai sao lai phai ma hoa Base64 trong Protocol ma khong gui truc tiep?
-> Tra loi: Du lieu gom cac chuoi tieng Viet, co the chua dau phay, dau cham, khoang trang hoac 
ky tu xuong dong. Neu khong ma hoa, khi dung ham split() se rat de bi cat nham cot, dan toi sai lech du lieu. 
Ma hoa Base64 dam bao moi chuoi chi gom cac ky tu ASCII tieu chuan an toan tuyet doi khi truyen qua Socket.

Cau 4: Tai sao phia Client khong goi truc tiep Server ma phai dung SwingWorker?
-> Tra loi: Giao dien Java Swing chay tren mot luong duy nhat la EDT (Event Dispatch Thread). 
Neu thuc hien ket noi mang tren luong nay, khi mang cham hoac Server chua phan hoi thi toan bo cua so 
giao dien se bi "Not Responding" (do, treo). SwingWorker giup day viec gui/nhan mang xuong luong nen 
(Background Thread), giu cho giao dien luon muot ma.

Cau 5: Rang buoc toan ven du lieu (Foreign Key Constraint) duoc thuc hien the nao?
-> Tra loi: Trong Store.java, truoc khi xoa mot cong dung, he thong duyet qua danh sach tat ca cac 
loai thuoc hien co. Neu co bat ky loai thuoc nao dang tham chieu toi cong dung nay thi Server lap tuc 
tu choi xoa va nem ngoai le thong bao ro ten loai thuoc dang vi pham rang buoc.
